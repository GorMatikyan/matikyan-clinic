# Content Sheets

These CSV files are the page-by-page handoff for management.

Files:

- `Home.csv`
- `Common.csv`
- `About.csv`
- `Doctors.csv`
- `Services.csv`
- `Reviews.csv`
- `FAQ.csv`
- `Contact.csv`

Recommended workflow:

1. Copy each CSV into a tab in Google Sheets.
2. Let management fill `HY` and `RU`.
3. Approve real clinic phone/address/email/hours/images.
4. Push approved content back into code.
5. Keep `Sanity` for `Blog` only.
