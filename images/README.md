# Image Intake Structure

Use these folders for approved image intake and processing.

Folders:
- source-originals: untouched originals from camera/photographer
- hero: homepage or top-section candidate images
- sections: reusable section images for homepage/about and similar blocks
- doctors: doctor portraits/headshots
- clinic-large: facade, interiors, equipment, rooms
- services: service-related real clinic images
- gallery: extra public gallery-ready images
- optimized: generated web-ready outputs
- archive: rejected, replaced, or old variants

Recommended workflow:
1. Put untouched originals in source-originals and optionally copy selected files into a target folder.
2. If you already know the usage, place copies into hero/sections/doctors/clinic-large/services/gallery.
3. Do not manually compress originals if possible.
4. We will generate final web assets into optimized.

Naming suggestion:
- doctor-svetlana-bagiyan-01.jpg
- clinic-facade-01.jpg
- hero-lobby-01.jpg
- service-implant-room-01.jpg

Do not rely on messenger-compressed copies if originals exist.
